# Focus Flow

A unified Pomodoro timer and task manager plugin for Omarchy. Assign tasks to focus sessions, track your workflow, and stay productive. Features include customizable durations, auto-start rules, and dynamic UI animations.

## Installation

To install and enable this plugin, run the following command in your terminal:

```bash
omarchy plugin add https://github.com/zaki2993/focusflow.git --enable
```

## Removal / Uninstallation

To safely disable and remove the plugin, run the following commands:

```bash
omarchy plugin remove zakarch.focusflow
rm -rf ~/.local/state/omarchy/zakarch.focusflow
```
